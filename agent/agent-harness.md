# Agent Harness：把约束装到验收一端

本文讨论人机协作中约束装置的设计。讨论不涉及提示词技巧，只处理四个问题。其一，约束为何难以作用于生成过程；其二，约束应安装在协作流程的哪一端；其三，该装置的收益如何度量；其四，装置运行之后系统性质有何变化。相关推演尚未定型，故本文停留在论文层，不进入规格。

人的工作量从生产转向治理的经过，已另文讨论；本文承接该文，讨论治理所依赖的装置。

## 一、参考与约束

本文区分两种约束力。参考指结构为模型所知，并影响其输出倾向，但违反结构仍然可能。约束指违反不会发生，或一经发生即被检出。二者不是程度差异，而是机制差异。

现行的结构安排停留在参考一端。原因在于，对模型行为的经验认识只能转化为引导。引导依赖在场：作者在场时输出可控，作者缺席时不成立。理解产生的是影响力，不是保证。

## 二、约束的作用点

把约束加在生成端，其效果受制于模型自身的行为倾向，并会持续回落到参考一端。

把约束加在验收端，则只需检查提交内容是否符合既定形状，无须干预生成过程。后者的可行性显著高于前者。

这一不对称决定了装置的安装位置：不在提示词内，而在生成与入库之间。

## 三、读路径与写路径

同一装置作用于不同路径，应采用不同标准。

读路径的错误代价有限。理解偏差导致一次质量不佳的回答，不改变库的内容，属于体验问题，可以通过调整提问方式缓解。

写路径的错误代价累积。分类错误、格式不符、与既有内容的关系未声明，一旦入库，后续读者会以其为准。故校验置于写入时刻。

校验对象不是模型的推理过程，而是提交内容是否符合容器形状。不符合者退回，由写入方修正。该装置的作用不在于使模型遵守规则，而在于使不符合规则的结果无法进入。区别在于通道而非措辞：措辞是请求，通道是拒绝。

## 四、标准的载体

校验需要标准，而标准主要存在于作者的经验中。

模型能够识别字段与层级，但不能识别字段所指的观察维度。同一组目录在模型侧是两个字符串，在作者侧是两类记忆：一类记当天的现场，一类记当天的认识。

由此产生的后果是：纠正与当次对话绑定，对话结束即失效；更换模型或调用方式，纠正不再生效。

改进方向不是更强的模型，而是把判断所需的信息封装进校验材料：结构说明、语义界线与正反例。

正反例的成本最低。作者无须以论文篇幅说明两类记忆的差异，只需提供两组对比例子，模型即可据此推断其余情形。

该材料的验收标准可以明确表述：未接触上下文的执行者阅读后，其判断与作者一致；边界案例可由材料自身解释，不必回询作者。

## 五、治理成本的度量

治理有成本。一条规则得以保留的条件是：其拦截的损失大于其造成的负担。

负担分三项。误拦指合格内容被拒绝，善后包括复核、改写与重新提交。漏过指问题在入库后被发现，代价随滞留时间上升。维护指阅读、修改与迁移规则所需的时间；规则数量增加时，单项规则可获得的注意力下降。

三项无须同时测量。漏过可先行测量，其不依赖额外装置，将存量按现行规则重新检查即可取得数据。误拦在写入拦截启用后测量。维护按季度摊销，不逐条计时。

数据齐备后，可以计算规则的净收益：拦截的损失减去误拦与维护。净收益为负者应予删除。删除前须确认其所拦截的错误是否仍然存在；若仍存在，则该规则并非多余，而是执行未到位。

另有一条纪律：度量不得成为新的负担。记录应依附于既有动作，复核、修复与迁移本已发生，附带记录即可。需要专门投入时间维护的度量，其自身即构成成本。

## 六、监督的执行者

该装置的失效风险主要来自无人维护。规则需要维护，报告需要阅读；阅读者一旦无暇顾及，装置即形同虚设。

因此，装置需要一个执行者位置。最初的做法由作者本人承担，成本高，且不可转移。

可行方案是使 AI 按作者的判断方式执行检查。不要求把每条检查写成条件分支，只需使其判断与作者一致。监督成本下降的原因不在结构简化，而在执行主体由作者本人转为按作者判断工作的 AI。

附带的收益是报告可被他人阅读。监督对象由「混乱」这一抽象概念转为具体违规，例如「该日志缺少日期」「该洞察未声明出处」。此类陈述不要求读者理解系统即可判断。

外部读者能够理解，原因不在系统简化，而在监督对象的具体化。

## 七、系统的自指

前述装置不仅作用于模型的输出，也改变系统自身的运行方式。

写入拦截检查每一次提交，体检覆盖全库状态，巡检回溯历史。三者指向同一问题：系统如何运转。

此前并非没有检查，但检查分散于各次对话，本次发现的问题在下次不再被记忆。纠正与对话绑定，对话终止即消失。所缺的不是工具，而是回路：缺少持续记录「何处出错、是否修正、是否复发」的位置。

回路建立之后，系统的观察对象发生变化。此前它只观察外部世界：业务、创作与认知；此后它开始观察自身对这些对象的记录——哪些已入库、哪些归类错误、哪些修正后复发。

这一变化的意义不在表述，而在成本结构。监督对象的具体化使外部人员能够判断，执行主体的转移使监督可以交付。两个条件同时成立，监督才可能从作者身上移出。

巡检数据同时显示了这一变化的限度。五百七十三次快照的重判结果为：历史上一千四百零五处问题曾入库，其中仅十九处由专项清理修正，其余或仍存在，或随文件重写而消失。

由此可见，回路提供了观测，但不提供纠正。纠正仍需排期。

因此，自指闭环的准确表述是：系统首次具备可查的运行记录，而非系统能够自动改善。记录的处置权仍在作者。

## 八、结论

harness 原指马具。马具不改变马的性情，它使马的力量可被使用，而不致失控。

用于 AI 的装置同理：其目的不在使模型更顺从，而在使输出经过一道可检查的关口。

最后一项要求是删除。规则若只增不减，数量增长至无人阅读之时，其所防范的错误仍在，而其自身成为新的错误。

可用的装置以一次性拦截为标志：同类错误不再第二次进入。
